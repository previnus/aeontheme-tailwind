== Description ==

Aeon Theme Tailwind is a classic WordPress theme with 40 modular page sections. Standard WordPress pages, posts, and archives work with the block editor. The optional page builder and Aeon Theme Options use ACF PRO.

== Installation ==

1. Install Aeon Theme Tailwind in wp-content/themes/aeontheme-tailwind and activate it under Appearance.
2. To use the builder, install and activate ACF PRO, then edit a page and choose Page Sections.
3. Use Aeon Theme Options for branding, header and footer, forms, and blog settings.
4. Preview and publish CSS overrides from Appearance > Customize > Additional CSS.

== Privacy ==

The theme does not send analytics or bundle site data. Plugins you configure handle embedded form submissions, storage, and mail delivery.
